Run Node with inspector:
node --inspect-brk app.js
This starts Node.js in debug mode and breaks on the first line.

VS Code launch.json:
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Debug App",
      "program": "${workspaceFolder}/app.js",
      "runtimeArgs": ["--inspect-brk"]
    }
  ]
}

How it works:
- --inspect-brk opens the debugger and pauses immediately.
- In VS Code, set breakpoints by clicking next to the line numbers.
- Start the config from Run and Debug → Debug App.
